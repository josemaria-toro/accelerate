# Zetatech.Accelerate
## Introducción
Librería perteneciente al framework **Zetatech Accelerate**, desarrollada por **Zeta Technologies** y que contiene los contratos de los principales componentes del framework.
## Estructura
```
├─ Zetatech
   ├─ Accelerate
      ├─ Application              ' Contratos para los componentes de la capa de aplicación.
      ├─ Caching                  ' Contratos para los componentes que permiten la gestión de la caché.
      ├─ Data                     ' Contratos para los componentes de la capa de acceso a datos.
      ├─ Domain                   ' Contratos para los componentes de la capa de dominio.
      ├─ Jobs                     ' Contratos para los componentes que gestionan la ejecución de procesos en segundo plano.
      ├─ Messaging                ' Contratos para los componentes que realizan la publicación y suscripción a colas de mensajería.
      ├─ Telemetry                ' Contratos para los componentes que realizan la gestión de datos de telemetría.
```
