# Zetatech Accelerate Framework
## Descripción
**Zetatech Accelerate** es un framework robusto para aplicaciones .NET que proporciona una arquitectura desacoplada y extensible. Desarrollado por **Zeta Technologies**, está diseñado para acelerar el desarrollo de aplicaciones empresariales modernas, ofreciendo patrones de diseño consolidados y componentes reutilizables.
## Proyectos
- [Accelerate](.docs/accelerate.md): proyecto que contiene los contratos de los componentes del framework.
- [Application](.docs/application.md): proyecto que contiene clases base y componentes de la capa de aplicación.
- [Configuration](.docs/configuration/configuration.md): proyecto que contiene métodos de extensión para añadir órigenes de configuración a las aplicaciones.
- [Data](.docs/data.md): proyecto que contiene clases base y componentes de la capa de acceso a datos.
- [Domain](.docs/domain.md): proyecto que contiene clases base y componentes de la capa de dominio.
- [Exceptions](.docs/exceptions.md): proyecto que contiene el catálogo de excepciones.
- [Jobs](.docs/jobs.md): proyecto que contiene clases base para procesos en segundo plano.
- [Logging](.docs/logging.md): proyecto que contiene clases base y componentes para el registro de información de diagnóstico.
- [Messaging](.docs/messaging.md): proyecto que contiene clases base y componentes para la suscripción y publicación de mensajería.
- [Serialization](.docs/serialization/serialization.md): proyecto que contiene clases base y componentes para la serialización / deserialización de objetos.
- [Telemetry](.docs/telemetry.md) proyecto que contiene clases base y componentes para el registro de información de telemetría.
