# Zetatech Accelerate Framework
## Descripción
**Zetatech Accelerate** es un framework robusto para aplicaciones .NET que proporciona una arquitectura desacoplada y extensible. Desarrollado por **Zeta Technologies**, está diseñado para acelerar el desarrollo de aplicaciones empresariales modernas, ofreciendo patrones de diseño consolidados y componentes reutilizables.
## Proyectos
- [Accelerate](.docs/accelerate.md): proyecto que contiene los componentes core del framework.
- [EntityFramework](.docs/entityframework.md): proyecto que contiene los componentes de la capa de acceso a datos que extienden las funcionalidades ofrecidas por EntityFramework.
- [RabbitMQ](.docs/rabbitmq.md): proyecto que contiene los componentes de mensajería que extienden las funcionalidades ofrecidas por RabbitMQ.
